# Sound credits

WORLDWORKS ships **no audio files**. Every sound (part "tock" notes, snap, ka-ching, Portal whoosh and chime, error buzz)
is synthesized at runtime with the browser's WebAudio API in `app/src/game/jobs/sound.ts`, written for this project.
There is nothing third-party to license. Music and effects start after the first user gesture; `?lowfx=1` starts them off, and the speaker popover toggles them.

If CC0 samples are added later (for example Kenney "Interface Sounds", https://kenney.nl/assets/interface-sounds, CC0),
list each file here with its source URL and licence.
